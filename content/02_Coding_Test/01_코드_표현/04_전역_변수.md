# 1. 전역 변수 수정: `global` 키워드
함수 내부에서 전역 변수에 새로운 값을 할당하려면 반드시 `global` 키워드가 필요하다. 키워드 없이 선언하면 파이썬은 이를 전역 변수가 아닌 새로운 **지역 변수**로 간주한다.

* **방법:** 함수 시작 부분에서 `global 변수명`을 선언한다.

```python
unused = 10

def update_unused():
    global unused  # 전역 변수 unused를 사용하겠다고 선언
    unused = 20    # 이제 전역 변수 값이 바뀜
```

# 2. 전역 변수 조회: 키워드 불필요
단순히 값을 읽기만 할 때는 `global`이 없어도 된다. 파이썬은 함수 내에 해당 변수가 없으면 자동으로 전역 스코프에서 찾는다.

```python
unused = 10

def print_unused():
    print(unused)  # 조회만 하므로 global 생략 가능
```

# 3. 주요 실수 및 예외 사례
* **UnboundLocalError:** 함수 내부에서 `global` 선언 없이 변수를 참조한 뒤, 아래쪽에서 해당 변수에 값을 할당하면 에러가 발생한다. 파이썬이 이를 지역 변수로 판단했는데, 할당 전에 참조했기 때문이다.
* **Mutable 객체(List, Dict):** 리스트의 요소를 수정하거나 추가(`.append()`)하는 행위는 변수 자체를 새로 할당하는 게 아니므로 `global` 선언 없이도 가능하다. 단, 리스트 자체를 새 리스트로 갈아치울 때는 `global`이 필요하다.
