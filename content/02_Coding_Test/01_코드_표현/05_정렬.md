# 1. `sort()` vs `sorted()`
가장 먼저 구분해야 할 것은 두 가지 방식의 차이입니다.
- **`a.sort()`**: **원본 리스트를 직접 변경**합니다 (In-place sort). 반환값이 `None`입니다.
- **`sorted(a)`**: 원본은 그대로 두고, **정렬된 새로운 리스트를 반환**합니다.
# 2. `key` 파라미터
C++에서는 복잡한 정렬을 위해 비교 함수(`cmp`)를 직접 짰지만, **Python에서는 `key` 파라미터와 `lambda`를 사용하면 훨씬 직관적입니다.**
#### 예제: 5로 나눈 나머지 순으로 정렬 (나머지가 같으면 크기 순)
``` python
arr = [5, 1, 6, 2, 7, 3, 4]

arr.sort(key=lambda x: (x % 5, x))

print(arr)
# 결과: [5, 1, 6, 2, 7, 3, 4] (나머지 0, 1, 2, 3, 4 순서)
```

- **원리:** Python의 튜플은 C++의 `pair`/`tuple`처럼 앞의 원소부터 차례대로 비교합니다. 따라서 `(나머지, 원래값)` 형태의 튜플을 만들어주면 알아서 다중 조건 정렬이 됩니다.
# 3. 다중 조건 정렬, 내림차순
**하나는 오름차순, 하나는 내림차순**이라면 어떻게 할까요?
**예:** "점수는 높은 순(내림차순), 점수가 같으면 이름 사전 순(오름차순)"
```python
students = [('Alice', 80), ('Bob', 90), ('Charlie', 80)]

# 점수에는 마이너스(-)를 붙여서 내림차순 효과를 냅니다.
# (숫자 타입일 때만 가능)
students.sort(key=lambda x: (-x[1], x[0]))

print(students)
# 결과: [('Bob', 90), ('Alice', 80), ('Charlie', 80)]
```
- 숫자가 아닌 경우(문자열 내림차순 등)에는 `reverse=True`를 전체에 걸거나, 조금 더 복잡하지만 `cmp_to_key`를 써야 할 수도 있습니다.
# 4. Python 정렬은 기본이 Stable Sort
Python의 sort와 sorted는 기본적으로 Stable Sort(안정 정렬)입니다.
- **의미:** 값이 같으면 기존의 순서가 유지됩니다.
- **활용 팁:** 여러 조건으로 정렬할 때, 중요도가 **낮은 조건부터** 차례대로 정렬해도 됩니다.
```python
    # 1. 이름 순 정렬 (차순위)
    data.sort(key=lambda x: x['name'])
    # 2. 점수 순 정렬 (최우선순위)
    # Stable하기 때문에 점수가 같으면 1번에서 정렬한 이름 순서가 유지됨
    data.sort(key=lambda x: x['score'], reverse=True)
```
