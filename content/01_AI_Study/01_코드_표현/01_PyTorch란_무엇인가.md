# PyTorch
파이썬의 딥러닝 프레임 워크이다.
# 동적 계산 그래프
PyTorch의 가장 큰 기술적 특징으로, 실행하면서 그래프를 정의하는 원칙을 따른다.(기존의 TensorFlow 1.x 등은 정적 계산 그래프를 사용했었다.)
- 코드를 실행하는 시점에서 데이터 흐름(그래프)이 만들어지기 때문에, 중간에 값을 확인하거나 에러를 잡는 디버깅이 매우 쉽다.
- 모델 구조를 실행 중에 마음대로 바꿀 수 있어, 입력 데이터의 길이나 형태가 계속 변하는 자연어 처리 연구에서 특히 강하다.
# 정적 계산 그래프
PyTorch에서 사용하는 것과 반대로 데이터를 넣기 전에 그래프의 구조를 미리 다 정의해두고 고정하는 방식이다.(Define-and-Run)
- 그래프가 고정되어 있어 메모리 사용량과 연산 속도를 미리 최적화하기 좋다. 따라서 연구보다는 대규모 서비스 배포에 유리하다. 예: vLLM(IVersatile Large Language Model), TGI(Text Generation Inference)
