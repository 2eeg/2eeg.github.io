## 커스텀 데이터셋 (Custom Dataset) 정의하기
PyTorch의 `torch.utils.data.Dataset`은 데이터를 저장하고 관리하는 그릇이다. 위에서는 이를 해당 클래스 직접 사용하였지만 이를 상속 받아 맞춤 데이터셋을 만들어 쓸 수도 있다.
### 왜 직접 만들어야 할까요?
단순히 `TensorDataset`을 써도 되지만, 커스텀 클래스를 만들면 다음과 같은 고급 작업이 가능해진다.
1.  **On-the-fly 전처리**: 모든 데이터를 미리 메모리에 정규화해서 올리는 것이 아니라, `__getitem__`에서 데이터를 불러올 때마다 실시간으로 노이즈를 추가하거나 변형(Augmentation)을 줄 수 있다.
2.  **메모리 효율**: 수만 장의 이미지를 한 번에 메모리에 올릴 수는 없다. `__init__`에는 이미지 경로만 저장해두고, `__getitem__`이 호출될 때만 이미지를 한 장씩 읽어오도록 설계하여 메모리 점유율을 획기적으로 낮출 수 있다.
3.  **다양한 데이터 소스**: SQL DB에서 직접 쿼리를 날려 데이터를 가져오거나, 여러 개의 CSV 파일을 병합해서 읽어오는 로직을 깔끔하게 캡슐화할 수 있다.

추상 클래스를 상속받아 다음 3가지 메서드를 반드시 구현해야 한다.
1.  **`__init__(self, ...)`**: 데이터를 불러오고 초기화하는 단계이다. (예: CSV 읽기, 이미지 경로 리스트 만들기)
2.  **`__len__(self)`**: 데이터셋의 총 샘플 개수를 반환한다.
3.  **`__getitem__(self, idx)`**: 특정 인덱스(`idx`)의 데이터를 가져와서 전처리를 수행하고, **(데이터, 라벨)** 형태의 텐서로 반환한다.

### 붓꽃 데이터를 활용한 커스텀 데이터셋 예시
```python
import torch
from torch.utils.data import Dataset

class IrisDataset(Dataset):
    def __init__(self, features, labels):
        # 1. 초기 데이터를 텐서로 변환하여 저장
        self.features = torch.tensor(features, dtype=torch.float32)
        self.labels = torch.tensor(labels, dtype=torch.long)

    def __len__(self):
        # 2. 전체 데이터 개수 반환
        return len(self.features)

    def __getitem__(self, idx):
        # 3. 인덱스에 해당하는 데이터 1개 반환
        x = self.features[idx]
        y = self.labels[idx]
        return x, y
```


## 2. 데이터 로더 (DataLoader) 활용하기
`DataLoader`는 우리가 만든 `Dataset`을 입력으로 받아, 학습에 필요한 기능을 제공하는 관리자이다.
### 주요 파라미터
* **`dataset`**: 앞서 정의한 커스텀 데이터셋 객체.
* **`batch_size`**: 한 번에 몇 개의 데이터를 묶어서 모델에 줄 것인가? (GPU 메모리에 맞춰 조절)
* **`shuffle`**: 데이터를 섞을 것인가? (학습 시에는 모델이 순서를 외우지 못하게 보통 `True`로 설정)
* **`num_workers`**: 데이터를 불러올 때 사용할 하위 프로세스 개수. (맥북이나 리눅스 환경에서 멀티코어를 활용해 속도를 높일 수 있다.)

```python
from torch.utils.data import DataLoader

# 데이터셋 객체 생성
train_ds = IrisDataset(X_train_scaled, y_train)

# 데이터 로더 생성
train_loader = DataLoader(train_ds, batch_size=16, shuffle=True, num_workers=0)

# 실제 학습 루프에서의 사용
for batch_idx, (data, target) in enumerate(train_loader):
    # data: [16, 4] 크기의 텐서 (배치 사이즈 16, 피쳐 4개)
    # target: [16] 크기의 텐서 (라벨 16개)
    pass
```


# 6. 모델 클래스 정의 (Model Definition)
`nn.Module`을 상속받아 간단한 형태의 신경망(`IrisNN`)을 구축합니다. 입력층, 은닉층, 그리고 활성화 함수인 `ReLU`를 통과해 3개의 클래스로 분류되도록 구성 함.

```python
import torch.nn as nn

class IrisNN(nn.Module):
    def __init__(self):
		super().__init__()
        self.fc1 = nn.Linear(4, 16)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(16, 3)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

model = IrisNN()
print(model)
```

# 6. 학습 및 평가 코드 (Training & Evaluation Loop)
모델을 실제 디바이스(CPU 또는 GPU)에 올리고 역전파를 통해 학습하는 루프를 작성한다. 손실 함수로는 `CrossEntropyLoss`를, 옵티마이저로는 `Adam`을 사용한다.

`torch.inference_mode()` 활용하기
평가(Evaluation) 단계에서는 기울기(Gradient) 계산이 필요 없다. 기존에는 `torch.no_grad()`를 많이 사용했지만, 이번 코드에서는 최신 버전에서 권장하는 **`torch.inference_mode()`** 를 적용했다. 이는 내부 런타임 오버헤드를 극단적으로 줄여주어 더 빠른 속도와 안전성을 보장하는 강력한 추론 전용 모드이다.

```python
import torch.optim as optim

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

epochs = 100
for epoch in range(epochs):
    model.train() # 학습 모드
    for X_batch, y_batch in train_loader:
        X_batch, y_batch = X_batch.to(device), y_batch.to(device)

        optimizer.zero_grad()
        outputs = model(X_batch)
        loss = criterion(outputs, y_batch)
        loss.backward()
        optimizer.step()

    # 10 에포크마다 평가 진행
    if (epoch + 1) % 10 == 0:
        model.eval() # 평가 모드
        with torch.inference_mode():
            test_loss = 0
            correct = 0
            for X_test_batch, y_test_batch in test_loader:
                X_test_batch, y_test_batch = X_test_batch.to(device), y_test_batch.to(device)

                test_outputs = model(X_test_batch)
                test_loss += criterion(test_outputs, y_test_batch).item()
                _, predicted = torch.max(test_outputs, 1)
                correct += (predicted == y_test_batch).sum().item()

        print(f'test_loss, accuracy in epoch {epoch + 1}: {test_loss / len(test_loader)}, {correct / len(test_dataset)}')
```
